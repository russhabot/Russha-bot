# ربات راشا کوین 🪙

## راه‌اندازی
1. در @BotFather ربات بسازید و توکن را بگیرید.
2. **مهم:** در BotFather دستور `/setprivacy` → ربات → **Disable**
   (وگرنه ربات پیام‌های عادی گروه را نمی‌بیند).
3. ```
   pip install -r requirements.txt
   cp .env.example .env      # توکن را داخلش بگذارید
   python bot.py
   ```
4. ربات را به گروه(ها) اضافه کنید. اگر نسخه‌ی قبلی را اجرا کرده بودید، دیتابیس خودکار مهاجرت می‌کند
   (کوین‌های هر کاربر در گروه‌های مختلف جمع می‌شود).

## دستورهای متنی (ربات هیچ دستور / ندارد و فقط داخل گروه‌ها کار می‌کند؛ پیوی نادیده گرفته می‌شود)
با نوشتن هر عبارت در گروه، منوی مربوطه با دکمه‌های شیشه‌ای همان‌جا برای همان شخص ارسال می‌شود.
دکمه‌ها فقط برای کسی که منو را باز کرده کار می‌کنند.

| بنویس | کار |
|---|---|
| پریویت / привет | ۱ تا ۵ راشا کوین (رندوم)، هر ۵ دقیقه، برای همه‌ی گروه‌ها یکسان |
| وضعیت (یا موجودی / static) | کیف پول، بانک، ودکا ساز و آمار |
| بانک روسی | منوی دکمه‌ای: واریز، برداشت، سرمایه‌گذاری، وام، پرداخت وام (مبلغ را هم با دکمه انتخاب می‌کنید) |
| واریز N / برداشت N | (میان‌بُر متنی) کیف پول ⇄ بانک |
| انتقال N @یوزرنیم (یا ریپلای) | از بانک به کیف پول دیگران |
| سرمایه گذاری N / برداشت سرمایه N | سود هر شب ۰۰:۰۰ تهران |
| وام N / پرداخت وام N | وام با کارمزد و بهره‌ی شبانه |
| ودکا ساز | خرید، برداشت (`برداشت ودکا`) و ارتقا (`ارتقا ودکا ساز`) |
| برترین روس | انتخاب بین جدول گروه و جهانی |
| راهنما | لیست دستورها |

به جای عدد می‌شود «همه» نوشت. ارقام فارسی هم پذیرفته می‌شود.

## تنظیم بالانس اقتصاد
همه‌ی اعداد (قیمت‌ها، درصدها، سرعت و ظرفیت ودکا ساز، …) در `.env` هستند؛ فرمول‌های سطح‌بندی ودکا ساز در `game.py`.

## توسعه
- **دستور متنی جدید:** یک تابع با `@text_command(regex)` (فایل جدید در `features/` + یک import در `features/__init__.py`)
- **دکمه‌ی جدید:** `@callback("prefix")`
- **تغییر دیتابیس:** یک آیتم به آخر `MIGRATIONS` در `db.py`؛ با اجرای بعدی خودکار اعمال می‌شود.
- **قوانین پولی** همه در `db.py` و داخل تراکنش اتمیک هستند تا با پیام‌های همزمان، پول تکراری ساخته نشود.
